# The Ashen Circuit v1.3

A playable 16-bit-style dungeon RPG prototype for 64-bit Ubuntu/Linux.

This release adds seamless Chrono Trigger-style active-time battles, visible
enemy encounters, armed battle stances, distance-aware run and jump attacks,
the supplied battle theme, a clearer compact combat HUD, and chest-based tomes
and permanent stat growth in place of character levels.

## Recommended download

Download `The_Ashen_Circuit-1.3-Ubuntu.zip`, extract it, then follow
`START_HERE.txt`. The included launcher starts the AppImage without requiring
FUSE, Python, administrator access, or installation.

The standalone AppImage and extracted portable archive are included as
alternatives. `SHA256SUMS-1.3.txt` can be used to verify each download.

## Notes

- Platform: Linux x86_64; packaged and tested on Ubuntu 24.04.
- Ubuntu 26.04 hardware testing is not yet available.
- Xbox-compatible controller and keyboard controls are supported.
- Save data is stored outside the AppImage under the standard XDG data folder.
- Full-playthrough balance and the target 90-minute pacing are not yet verified.
