THE ASHEN CIRCUIT 1.3 - START HERE
==================================

System requirement
------------------
64-bit Intel/AMD Linux (x86_64). This release is packaged for Ubuntu.

Recommended start method
------------------------
1. Download The_Ashen_Circuit-1.3-Ubuntu.zip from the GitHub release.
2. Extract the ZIP. Do not run the files from inside the archive.
3. Open a terminal in the extracted folder.
4. Run:

   sh ./Play-The-Ashen-Circuit.sh

The launcher keeps the AppImage beside it and uses AppImage's extraction mode,
so it does not need FUSE, Python, administrator access, or an installation.

Starting the AppImage by itself
-------------------------------
If you downloaded only the AppImage, open a terminal in its folder and run:

   chmod +x ./The_Ashen_Circuit-1.3-x86_64.AppImage
   ./The_Ashen_Circuit-1.3-x86_64.AppImage --appimage-extract-and-run

Double-clicking the AppImage may fail on newer Ubuntu systems when libfuse.so.2
is unavailable. The included launcher and the --appimage-extract-and-run option
avoid that requirement.

Alternative portable build
--------------------------
Extract The_Ashen_Circuit-1.3-Linux-Portable.tar.gz, open its
The-Ashen-Circuit folder, and run:

   sh ./AppRun

Keep every file in that folder together.

Controls
--------
Move/select:                Arrow keys or WASD / Xbox D-pad or left stick
Confirm/interact:           Z or Enter / Xbox A
Cancel/field menu:          X or Escape / Xbox B or Start
Switch ready combatant:     Q or E / Xbox LB or RB
New game at title:          N / Xbox Y
Quick-save outside combat:  F5
Fullscreen:                 F11

Save and log locations
----------------------
Save:  ~/.local/share/ashen-circuit/save.json
Logs:  ~/.local/state/ashen-circuit/

If the game will not start, send the files from the Logs folder with a
description of what happened.
